# MB Homebrew tap

MB 2.0.0 packages the Micro.blog CLI and optional local MCP server for agents.

[Cold source installation, RC4-to-stable upgrade and fresh bottle pour passed](https://github.com/jthingelstad/homebrew-mb/actions/runs/37242182828) on Apple Silicon, macOS 26, at the default `/opt/homebrew` prefix. Both jobs completed installed tests and revoked formula trust.

[Stable release](https://github.com/jthingelstad/mb/releases/tag/v2.0.0) and [exact bottle/checksums/evidence](https://github.com/jthingelstad/homebrew-mb/releases/tag/mb-v2.0.0) are published. Source commit: `34263c38b5e76037b8d71ab0409427e6fefe82a8`.

The final fresh-runner public tap/URL installation check is pending. Verified public installation instructions will follow that result. macOS 27, Intel, Linux and other prefixes are not certified. No live Micro.blog writes were tested. Workflows are manual with `contents: read`; there is no automatic updater or publisher.
